How to Label Fallacies

Read each argument carefully and choose the fallacy that best matches the reasoning error being used. This is a manual, non-AI-assisted task: do not use AI tools when making your selection.

Fallacy Types

Ad Hominem — Attacks the person instead of the argument.

Ad Populum — Claims something is true because many people believe it.

Appeal to Authority — Relies on an authority figure instead of evidence.

Appeal to Ignorance — Claims a statement is true because it has not been disproven.

Cherry Picking — Selects only evidence that supports a claim while ignoring contrary evidence.

Circular Reasoning — Uses the conclusion as a premise.

Equivocation — Uses a word or phrase with multiple meanings to mislead.

False Causality — Assumes one event caused another without proof.

False Dilemma — Presents only two options when more exist.

Hasty Generalization — Draws a broad conclusion from too little evidence.

Loaded Question — Phrasing a question that presumes an unproven claim.

Red Herring — Diverts attention away from the real issue.

Slippery Slope — Claims a minor action will inevitably lead to extreme outcomes.

The Bandwagon — Suggests a claim is true because it is popular.

Tips

  • Choose the single best match when more than one fallacy seems possible.
  • Focus on the reasoning, not whether the claim is true in reality.
  • Be consistent across similar arguments.
